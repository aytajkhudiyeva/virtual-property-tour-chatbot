# Virtual Property Tour Chatbot

Independent illustrated tour concept. Visitors switch between three scenes, ask questions grounded in a fictional property fixture, and express viewing interest. With `OPENAI_API_KEY`, a server-side AI call can answer additional grounded questions. Without a key, fixed responses keep it runnable.

Node 20+: `npm start`, open `http://127.0.0.1:4205`, and run `npm test`. The visuals and details do not represent a real listing. No enquiry is sent or stored. Replace illustrations with licensed tour media and verify all property facts before using with a client.

## Live demo

[Open the interactive demo](https://aytajkhudiyeva.github.io/virtual-property-tour-chatbot/). The GitHub Pages version runs in the browser with deterministic sample logic and no server-side AI or external account integration. Use fictional data. The Node server remains available for local development and integration work.
